Tiga Peran Sistem & Mesin Protokol

Alur end-to-end terpisah antara pengirim pesan darurat, pihak penyadap lalu lintas jaringan, dan posko penanganan darurat sebagai pihak penerima resmi.

01 PENGIRIM

Halaman Pengirim

  • Pembangkitan pasangan kunci RSA pengirim
  • Input nama, waktu, pesan & GPS latitude/longitude
  • Hashing manual & Digital Signature (private key)
  • Enkripsi payload dengan public key pusat

02 PENYADAP

Halaman Penyadap (MITM)

  • Sadap paket di jalan (signature & metadata terbuka)
  • Kerahasiaan terjaga: isi pesan tak bisa dibaca
  • Manipulasi isi pesan atau koordinat palsu
  • Enkripsi ulang + tempel signature lama

03 PUSAT

Halaman Pusat Darurat

  • Pembangkitan & registrasi public key pusat ke DB
  • Inbox pesan masuk tersinkronisasi database
  • Dekripsi blok dengan private key pusat darurat
  • Verifikasi keaslian signature pengirim & anti-hoax
Buka Pusat Darurat →
04 RSA MURNI

Matematika Mandiri

  • Extended Euclidean Algorithm (Bezout Identity)
  • Modular Inverse manual tanpa helper bawaan
  • Square-and-Multiply manual untuk modPow
  • Encoding blok berbasis 3-digit ASCII dinamis

Integritas Data Matematis Tanpa Ketergantungan Eksternal

Sistem ini dibangun untuk menyelesaikan masalah nyata dalam layanan darurat publik: banyaknya laporan palsu (hoax), kemungkinan pemalsuan koordinat ambulans/evakuasi di tengah jalan, dan ketiadaan bukti otentikasi identitas pengirim.

1. Kerahasiaan (Confidentiality) Paket dienkripsi menggunakan public key Pusat Darurat. Penyadap di jaringan tidak bisa membaca teks pesan asli.
2. Keaslian & Non-Repudiasi (Authenticity) Hanya pengirim yang memiliki private key-nya sendiri untuk menghasilkan digital signature yang valid.
3. Deteksi Manipulasi (Integrity) Perubahan 1 karakter ataupun koordinat koma terkecil akan menghasilkan hash berbeda — pesan ditolak sebagai tidak valid.

Panduan Demo Presentasi (Ikuti Urutan Skenario 3 Tab)
TAHAP 1 Pusat Darurat

Buka tab /center → Klik [Generate & Daftarkan] → Kunci publik pusat terdaftar di database.

TAHAP 2 Pengirim SOS

Buka tab /sender → Klik [Isi Contoh] → [Generate Keys] → [Generate Signature] → [Encrypt & Send].

TAHAP 3 Pusat Memverifikasi

Kembali ke /center → Klik [Muat Inbox] → Pilih baris pesan → [Verifikasi Signature] → ✓ SOS VALID.

TAHAP 4 Penyadap (MITM)

Buka tab /attacker → Klik [Muat Paket Disadap] → Pilih pesan → [Serang — Ganti Isi Paket] (lokasi palsu).

TAHAP 5 Deteksi Pemalsuan

Kembali ke /center → Muat ulang inbox → Pilih paket ditamper → [Verifikasi] → ✗ SOS TIDAK VALID.

TAHAP 6 Pemulihan Paket

Kembali ke /attacker → Klik [Reset ke Paket Asli] → Verifikasi lagi di /center → ✓ SOS VALID kembali.
