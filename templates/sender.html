1 Key Generation

Pasangan Kunci Pengirim

Isi dua bilangan prima p, q dan eksponen publik e. Seluruh tahap RSA tampil di bawah. Private key disimpan hanya di browser (localStorage) — tidak pernah dikirim ke database.

2 Sender SOS

Hash + Digital Signature

Payload digabung: Nama|Latitude|Longitude|Waktu|Pesan · hash = (jumlah ASCII) mod 10000 · signature = hashd mod n

Butuh izin lokasi (localhost/HTTPS). Input manual tersedia sebagai fallback.

3 Encryption Process

Public Key Pusat Darurat

Tiap karakter diubah jadi 3 digit ASCII, digabung menjadi blok (nilai blok selalu < n pusat), lalu cipher = bloke mod n. Paket berisi ciphertext + signature + public key pengirim.
